# OmniGlow captures

De capture-exporten in deze map zijn gemaakt met de ESP32-RMT-analyzer. De originele Hue-controller bleef tijdens het meten aan de strip gekoppeld; de ESP32 hing alleen als hoogohmige meetingang aan de DATA-lijn.

Formaat per resultaat:

```text
LABEL: naam
BYTES: 806 hex-bytes
```

De labels beschrijven de ingestelde toestand in de Hue-app. Zie `protocol-analysis.md` voor de eerste analyse.
